# Social SEO Hub - Topic 17

Website demo cho chủ đề "Social Signals & Social Media Optimization for SEO".

## Chạy trên máy
Mở `index.html` bằng trình duyệt hoặc dùng Live Server trong VS Code.

## Đưa lên GitHub Pages
1. Tạo repository tên `social-seo-hub`.
2. Upload `index.html`, `style.css`, `script.js`, `robots.txt`, `sitemap.xml`.
3. Vào Settings → Pages.
4. Chọn Deploy from a branch → `main` → `/root`.
5. Lưu và chờ GitHub Pages triển khai.
6. Website sẽ có dạng:
   https://TEN-GITHUB-CUA-BAN.github.io/social-seo-hub/

Sau khi có URL thật, sửa URL trong `robots.txt` và `sitemap.xml`.
